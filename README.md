# LimanLab v0.5 · Liquid Glass Homelab

Лёгкий интерактивный прототип домашней серверной панели с фирменным **Liquid Glass**: прозрачные линзованные карточки, мягкие отражения, живые SVG-превью и семь разделов.

> **Это демо на вымышленных данных.** Никаких соединений с Docker, Hindsight, Immich или другими сервисами пока нет. Все команды запуска/остановки, резервного копирования и управления агентами демонстрационные.

## Что нового в v0.5

- Полностью перенастроен оптический материал: слабая окраска, тонкая световая кромка, внутренняя глубина, спокойный glow.
- Живые миниатюры: семь локальных SVG-сцен для галерей Jellyfin и Immich, динамический Docker, Hindsight, Cognee, OpenCode и Tailscale.
- Компактные плитки на узких экранах, улучшенная мобильная навигация и типографика.
- Приветствие по времени Киева, а не постоянно «Добрый вечер».
- Настройки света, стекла и анимации; учитывается `prefers-reduced-motion`.
- Никаких CDN и внешних изображений, работает офлайн, в том числе из `file://`.

## Запуск

**Без сборки**: откройте `index.html` в браузере (рядом должны быть CSS/JS и папка `assets`).

**Docker:**

```bash
docker compose up -d --build
# http://localhost:8088
```

**Один HTML для смартфона:** используйте отдельно собранный `LimanLab-v0.5-mobile.html`. В нём CSS, JS и SVG встроены внутрь.

## Производительность и безопасность

- На мобильных и сенсорных устройствах рефракция работает в облегчённом режиме, без тяжёлого SVG displacement на каждый кадр. Блики статичнее, но стекло остаётся прозрачным.
- Кнопки и метрики не имеют доступа к хосту. Для реальных данных нужен отдельный backend с аутентификацией, ограниченными правами, аудитом и подтверждениями опасных действий.
- Секреты, токены и сокет Docker нельзя помещать во фронтенд.

Репозиторий ранее носил имя `aurora` и был повторно использован по просьбе владельца; историю прежних коммитов Git не переписывает.
