# ✨ LimanLab — Liquid Glass Homelab UI v0.4

Интерактивный прототип персональной панели управления домашним сервером с анимированными плитками сервисов и интерфейсом в стиле сине-фиолетового Liquid Glass.

**Статус: фронтенд-демо.** Метрики и состояние сервисов вымышленные. Действия с контейнерами, терминалом и бэкапами ничего не меняют на настоящем сервере. Никакие реальные токены, IP или пароли в исходники не записаны.

## Возможности

- Главная с анимированными плитками Docker, Jellyfin, Immich, Hindsight, Cognee, OpenCode, Tailscale.
- Сервисы: поиск, фильтры, выбор контейнеров, просмотр деталей и демонстрация команд.
- Мониторинг: CPU, RAM, диски, сеть, задержки, аптайм, журналы.
- Хранилище, бэкапы, сеть и VPN, ИИ-агенты и их задачи.
- Настройки визуального стиля: цвет, стекло, размытие и обои.
- Адаптивный интерфейс, мобильное меню, поддержка reduced motion.
- Без внешних CDN, npm и фреймворков; собственные SVG и CSS-анимации.

## Запуск

Откройте `index.html` непосредственно в браузере. Для локального веб-сервера:

```bash
python3 -m http.server 8088
```

Или Docker:

```bash
docker compose up -d --build
# http://localhost:8088
```

## Структура

- `index.html` — HTML-разметка, иконка и метаданные
- `styles.css` — стекло, сетки, анимации, адаптивность
- `app.js` — вкладки, виджеты, события, демоданные
- `Dockerfile`, `compose.yaml` — статический nginx-контейнер

## Этап 2: реальное подключение

Подключить backend-посредник с ограниченными правами для Docker API, метрик (Prometheus/Node Exporter/cAdvisor), сервисов Immich / Jellyfin / Hindsight / Cognee, Tailscale и статуса Duplicati. Все секреты хранить на сервере. Для Stop/Restart/Delete/Restore предусмотреть авторизацию, подтверждения и аудит. **Не публиковать Docker socket напрямую в веб-интерфейс.**

## Происхождение репозитория

В октябре 2026 года репозиторий `aurora` был повторно использован для проекта LimanLab по решению владельца. Содержимое прежнего проекта убрано из актуальной ветки; его история коммитов сохранена.

## Liquid Glass v0.3

Добавлен слой `liquid-glass.css`: световые кромки, преломляющие линзы, движущиеся блики, интерактивная подсветка и лёгкий 3D-tilt. В настройках появилась регулировка преломления и переключатель живых эффектов. На мобильных устройствах и при `prefers-reduced-motion` анимации ограничиваются. Все показатели и действия остаются демонстрационными.

## Liquid Glass v0.4

Главное изменение: настоящий прозрачный слой, видимый космический фон `aurora-landscape.svg` под всеми карточками, самостоятельная оптика в `glass-refraction.css`, сильный световой кант, динамический блик, линзы со смещённой копией фона и фильтром SVG displacement на hover. Меню и виджеты сохраняют анимацию. На touch и при prefers-reduced-motion искажение отключается. В браузере без backdrop-filter предусмотрен контрастный fallback. Все показатели — демо.

Запуск: `docker compose up -d --build` → http://localhost:8088 (или открыть `index.html`).
